# 检索评估集 v1（2026-08-24）

## 目的
验证小说萃取检索质量（任务 2，项目书第 10 章）。检索层改动（低置信度过滤 + 标签加权）完成后首次跑分。

## 方法
- **Query 集**：27 个，覆盖场景 TOP6（谈判 5 / 危机 4 / 投资 4 / 风险 4 / 商业博弈 3 / 领导力 2 / 通用决策 2）+ 边界 3（玄幻修仙、恋爱分手、美食菜谱——预期低相关）
- **检索**：hybrid_search top_k=10（FTS5 + ChromaDB RRF 融合，低置信度过滤，标签加权生效）
- **判定**：DeepSeek flash 逐条判 relevant / partial / irrelevant（基于 title + content 前 120 字）
- **脚本**：eval_retrieval.py（--collect-only / --judge-only）

## 结果（270 条判定）

| 口径 | 数值 |
|---|---|
| relevant（严格相关） | 102 / 270 = 37.8% |
| relevant + partial（可用相关） | 217 / 270 = 80.4% |
| irrelevant | 53 / 270 = 19.6% |
| Precision@5（严格） | 44.4% |
| Precision@10（严格） | 37.8% |
| 边界 query 误召（relevant） | 0 / 30 |

## 结论
1. **检索质量合格**（按产品定位"决策提醒清单"）：80.4% 结果可用，边界 query 零误召。
2. **严格相关率偏低是判定口径问题，不是检索问题**：卡是去情节化的泛化方法论（"在流动性危机中，决策者应…"），对具体查询词天然多为 partial。抽检"危机 银行 挤兑"top5 全部是流动性/系统性危机内容，实际质量高。
3. **标签加权影响排序已验证**：加权后按 score 重排，核心标签命中卡排前（实测"风险管理 仓位 建仓"top2 都是风险管理标签卡）。
4. **已知弱项**：止盈类卡多、止损类卡少（"投资 止损 割肉"仅 1 relevant）——本书内容分布使然，非检索缺陷。
